# 动画素材生成记录

- 服务：`micu-image` MCP
- 模型：`gpt-image-2`
- 输出尺寸：`1024x1024`
- 布局：4 列 × 2 行，共 8 帧
- 参考图：`work/reference-clean.png`（侧爬）；其余动作使用已确认的角色特征生成

## 通用提示

制作黄色3D卡通小猴吉祥物的八帧动画精灵图，严格四列两行。角色始终统一：金黄色短毛、奶油色面部和肚皮、绿色大眼睛、粉色小鼻子、圆耳朵、棕色手脚、短卷尾巴、头顶三撮毛，风格可爱夸张、圆润精致。每格只有一只完整小猴，大小、镜头和光照一致，留足空白，不裁切、不重叠。背景必须是纯色洋红 `#FF00FF`。不要文字、数字、边框、分隔线、水印、地面、投影、道具、场景、特效和其他角色。

## 动作补充

- `idle`：八帧依次表现呼吸、眨眼、轻微歪头、耳朵动一下、尾巴摆动，再自然回到起始姿势。
- `crawl`：向屏幕右侧四肢爬行，对角肢体交替，表现重量转移、身体压缩和抬升、后腿蹬地、手掌着地和尾巴跟随。
- `climb`：沿看不见的竖直窗口边缘向上攀爬，左右手交替向上够，反侧脚交替蹬踏，身体拉伸和压缩，尾巴帮助平衡。
- `hang`：双手抓住看不见的水平窗口下沿倒挂，腿轻轻蜷起再伸展，身体左右摆动，尾巴跟随摆动。
- `jump`：预备下蹲、双腿蹬地、起跳、上升、腾空最高点、下降、双脚着地、缓冲回稳。
- `sleep`：侧卧蜷缩，闭眼，胸腹缓慢呼吸，耳朵偶尔轻动，尾巴轻微松紧变化；不要字母和睡眠符号。

原始生成图位于 `Assets/Source/raw`，色键透明图位于 `Assets/Source/transparent`。最终图集由 `tools/build_animation_atlas.py` 确定性生成。
